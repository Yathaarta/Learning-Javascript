In this repository, I track my progress and learnings of JavaScript as I master everything from core basics to advanced OOP. This serves as a live documentation of my coding journey and a home for all my practice projects.

- **Logic:** Control flow, Iterators, and Events.
- **Advanced:** DOM manipulation, Classes, and Object-Oriented Programming (OOP).
